# VIRETO 2026 Winter Marketing Proposal

비레토 겨울가전 메타 광고 및 자사몰 전환율 개선 제안서입니다.

## 신규 GitHub Pages 사이트 만들기
1. GitHub에서 새 저장소 `vireto-marketing` 생성 (Public).
2. 이 ZIP을 **압축 해제**하고 안에 있는 `index.html`, `README.md`를 저장소 최상위(root)에 업로드합니다. ZIP 파일 자체를 업로드하지 마세요.
3. 저장소의 Settings → Pages → Build and deployment → Source: Deploy from a branch를 선택합니다.
4. Branch: `main`, Folder: `/(root)`를 선택하고 Save를 누릅니다.
5. 배포 후 `https://<GitHub사용자명>.github.io/vireto-marketing/` 에서 확인합니다.

※ 기존 저장소는 수정하지 않습니다. 사이트는 공개되므로 민감한 제안 정보는 올리지 마세요.
